I run my own XMPP (Jabber) server. If you'd rather talk somewhere federated and self-hosted than over a proprietary platform, this is the way to reach me directly.

My address

0x@cigar.sh

Add this as a contact from any XMPP client, on any server — XMPP is federated, so you don't need an account on cigar.sh to message me.

Server details

  • Domain: cigar.sh
  • Client-to-server port: 5222 (STARTTLS) / 5223 (direct TLS)
  • Registration: in-band registration is disabled — accounts on this server are invite-only. If you specifically want an @cigar.sh address rather than just adding me as a contact, email or reach out first.
  • Encryption: OMEMO is supported and preferred for anything sensitive.

Getting started

If you don't already have an XMPP account, any of these clients will get you talking within a few minutes:

  • Conversations (Android) — the most straightforward option, supports OMEMO out of the box.
  • Dino (Linux/desktop) — clean, minimal, OMEMO supported.
  • Gajim (Windows/Linux/macOS) — more configurable, plugin support.
  • Monal (iOS/macOS) — solid option on Apple platforms.

Pick a public server to register on (or your own), then add 0x@cigar.sh as a contact and send a subscription request. I'll accept it and we're good to go.
